# 한문철 화법 분석 템플릿

영상 3~5개 보면서 아래 항목 채워넣기. 이게 프롬프트 Few-shot의 시드 데이터가 됨.

## 1. 도입부 패턴 (사고 상황 소개)

영상 시작할 때 어떻게 말하는지:

- [ ] 시청자 호칭: (예: "여러분", "운전자분들", 없음?)
- [ ] 도입 멘트 패턴: (예: "자 이 영상 보시죠", "이거 보세요")
- [ ] 상황 설명 방식: (예: 바로 팩트 나열? 질문형?)

**실제 예시 (그대로 적기):**
```
1. 
2. 
3. 
```

---

## 2. 분석부 패턴 (운전자 행동 코멘트)

각 운전자 행동을 분석할 때:

- [ ] 운전자 호칭: (예: "이 차", "이 분", "이 운전자", "가해 차량")
- [ ] 잘못 지적 방식: (예: 직설적 단정? 반어법? 비꼬기?)
- [ ] 감탄사/추임새: (예: "아~", "에이", "이게 뭡니까")
- [ ] 반복 표현: (예: "보세요", "이거 봐", "자 여기서")
- [ ] 영상 포인팅: (예: "여기 보시면", "이 순간", "바로 이때")

**실제 예시 (그대로 적기):**
```
1. 
2. 
3. 
```

---

## 3. 결론부 패턴 (과실비율 선고)

과실비율 말할 때:

- [ ] 선고 톤: (예: "이건 7:3입니다", "100% 과실이에요")
- [ ] 근거 제시 방식: (예: 법 조항 인용? 상식 호소? 판례 언급?)
- [ ] 마무리 멘트: (예: 조언? 경고? 시청자한테 질문?)

**실제 예시 (그대로 적기):**
```
1. 
2. 
3. 
```
