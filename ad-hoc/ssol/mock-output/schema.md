# 릴스 편집 스펙: 문철어 스크립트 JSON

> **이 문서의 대상**: Reels_Composer(영상 편집 모듈) 개발자
> 
> AI가 생성한 이 JSON을 받으면, 원본 블랙박스 영상 + TTS 나레이션을 조합해서 60초 릴스를 만들면 됩니다.

---

## 한 줄 요약

```
이 JSON = "어떤 나레이션을 깔고" + "블랙박스 영상 어디를 어떻게 보여줄지" 의 편집 지시서
```

---

## 전체 구조 한눈에 보기

```
{
  "script": {
    "intro":      { ... }   ← 도입부 (8~10초): 사고 상황 한 줄 소개
    "analysis":   { ... }   ← 분석부 (30~40초): 운전자별 행동 분석 (메인)
    "conclusion": { ... }   ← 결론부 (10~15초): 과실비율 선고
  },
  "total_duration_sec": 60,   ← 릴스 총 길이 목표
  "style_notes": "..."        ← 참고용 메모 (무시해도 됨)
}
```

**편집 순서**: intro → analysis → conclusion 순서대로 이어붙이면 완성.

---

## 각 섹션 필드 설명

### `text` — 나레이션 대본

```json
"text": "자 이 영상 보시죠. 편도 2차로에서 **쾅!** 추돌사고입니다."
```

- Voice_Generator가 이걸로 TTS 음성(MP3)을 만듦
- **편집자가 할 일**: 이 텍스트로 자막 트랙 생성
- `**강조**` 부분 → 자막에서 색상/크기 하이라이트 처리

### `duration_sec` — 이 파트의 시간 (초)

```json
"duration_sec": 38
```

- 나레이션 음성 길이 = 이 값
- **편집자가 할 일**: clips를 이어붙인 영상 길이가 이 값과 맞아야 함
- 클립이 모자라면 마지막 클립을 늘리고, 넘치면 잘라야 함

### `emphasis` — 강조 키워드

```json
"emphasis": ["핸드폰", "70대 30"]
```

- **편집자가 할 일**: 자막에서 이 단어들 하이라이트 (노란색, 볼드, 크기 키우기 등)
- 선택사항: 해당 키워드 나올 때 화면에 텍스트 오버레이 효과 추가

### `clips` — 영상 편집 지시 (핵심!)

```json
"clips": [
  {"start": "00:01", "end": "00:03", "effect": "normal", "desc": "정상 주행"},
  {"start": "00:03", "end": "00:05", "effect": "slow_2x", "desc": "사고 순간 슬로우"},
  {"start": "00:03", "end": "00:05", "effect": "replay", "desc": "다시보기"}
]
```

**순서대로 이어붙이면 됨.** 위 예시라면:
1. 블랙박스 00:01~00:03 원속 재생 (2초)
2. 블랙박스 00:03~00:05 슬로우모션 (원본 2초 → 재생 4초)
3. 블랙박스 00:03~00:05 다시 한번 원속 재생 (2초)
4. → 총 8초 영상

---

## clip 필드 상세

| 필드 | 뭔지 | 예시 |
|------|------|------|
| `start` | 원본 블랙박스에서 자를 시작점 | `"00:03"`, `"00:03.5"` |
| `end` | 원본 블랙박스에서 자를 끝점 | `"00:05"` |
| `effect` | 어떻게 재생할지 | `"slow_2x"` |
| `desc` | 이 클립이 뭘 보여주는 건지 (편집 참고용) | `"충돌 순간 슬로우"` |

---

## effect 종류 (5가지)

| effect | 재생 속도 | 실제 재생 시간 | 언제 쓰는지 |
|--------|----------|--------------|------------|
| `normal` | 1x (원속) | = 원본 길이 | 일반 주행, 상황 설명 |
| `slow_2x` | 0.5x | = 원본 × 2 | 사고 직전, 중요 순간 강조 |
| `slow_4x` | 0.25x | = 원본 × 4 | 충돌 순간 극적 연출 |
| `replay` | 1x (원속) | = 원본 길이 | "다시 보세요" — 같은 구간 반복 |
| `freeze` | 정지 | 자유 (duration_sec에 맞춰 조절) | 과실비율 선고, 판결 순간 |

### 재생 시간 계산 예시

```
원본 구간: 00:03 ~ 00:05 (2초)

effect: normal  → 재생 2초
effect: slow_2x → 재생 4초 (2 × 2)
effect: slow_4x → 재생 8초 (2 × 4)
effect: replay  → 재생 2초 (같은 거 한번 더)
effect: freeze  → 재생 N초 (남은 시간 채우기)
```

---

## 편집 워크플로우

```
1. JSON 파싱
2. 섹션별 루프 (intro → analysis → conclusion):
   a. clips 배열 순회
   b. 원본 블랙박스에서 start~end 구간 추출
   c. effect 적용 (속도 변경 / 정지 / 반복)
   d. 이어붙이기
   e. duration_sec에 맞게 미세 조정
3. 나레이션 MP3 오버레이 (각 섹션 시작점에 맞춰)
4. 자막 트랙 추가 (text 기반, emphasis 하이라이트)
5. 9:16 세로 비율로 출력
```

---

## 시간 맞추기 규칙

```
각 섹션의 clips 재생시간 합 ≈ duration_sec ≈ 나레이션 MP3 길이
전체 합: intro + analysis + conclusion ≈ total_duration_sec (60초)
```

**만약 안 맞으면?**
- clips 합 < duration_sec → 마지막 클립을 freeze로 늘리기
- clips 합 > duration_sec → 마지막 클립 끝 자르기
- 약간의 오차(±2초)는 허용

## 실제 출력 예시 (추돌사고)

```json
{
  "script": {
    "intro": {
      "text": "자 이 영상 보시죠. 편도 2차로에서 앞차 뒤차 달리고 있는데 갑자기 **쾅!**",
      "duration_sec": 8,
      "emphasis": ["쾅"],
      "clips": [
        {"start": "00:00", "end": "00:03", "effect": "normal", "desc": "두 차량 주행"},
        {"start": "00:05", "end": "00:06", "effect": "normal", "desc": "충돌 장면"}
      ]
    },
    "analysis": {
      "text": "여기 보세요. 뒤에 차 **핸드폰** 보고 있어요. 에이~ 앞차 서는 줄도 모르고 그대로 **박아버려요**.",
      "duration_sec": 38,
      "emphasis": ["핸드폰", "박아버려요"],
      "clips": [
        {"start": "00:01", "end": "00:03", "effect": "normal", "desc": "정상 주행"},
        {"start": "00:03", "end": "00:04", "effect": "slow_2x", "desc": "앞차 급정거"},
        {"start": "00:04", "end": "00:05", "effect": "normal", "desc": "뒤차 전방주시 태만"},
        {"start": "00:05", "end": "00:06", "effect": "slow_4x", "desc": "충돌 극슬로우"},
        {"start": "00:05", "end": "00:06", "effect": "replay", "desc": "충돌 다시보기"}
      ]
    },
    "conclusion": {
      "text": "이건 **70대 30**입니다. 안전거리 안 지키고 핸드폰 본 뒤차 70% 과실.",
      "duration_sec": 14,
      "emphasis": ["70대 30"],
      "clips": [
        {"start": "00:05", "end": "00:06", "effect": "freeze", "desc": "충돌 정지화면"},
        {"start": "00:00", "end": "00:06", "effect": "slow_2x", "desc": "전체 요약"}
      ]
    }
  },
  "total_duration_sec": 60,
  "style_notes": "한문철 화법 적용"
}
```

### 이 예시의 타임라인 시각화

```
[0s]─────────[8s]──────────────────────────────[46s]──────────[60s]
│   INTRO    │           ANALYSIS              │  CONCLUSION  │
│            │                                  │              │
│ 주행(3s)   │ 주행(2s)→급정거 슬로우(2s)→     │ 정지(4s)→   │
│ 충돌(1s)   │ 태만(1s)→극슬로우(4s)→다시(1s)  │ 전체요약(6s)│
│ +여백(4s)  │ +여백 조정                       │ +여백(4s)   │
│            │                                  │              │
│ 🎤나레이션  │ 🎤나레이션                       │ 🎤나레이션   │
│ 📝자막     │ 📝자막 (핸드폰 하이라이트)       │ 📝자막      │
└────────────┴──────────────────────────────────┴──────────────┘
```

## 입력으로 필요한 것

| 입력 | 출처 | 설명 |
|------|------|------|
| 이 JSON | Muncheol_Translator | 편집 지시서 |
| 원본 블랙박스 MP4 | Video_Uploader (S3) | clips에서 구간 추출할 소스 |
| 나레이션 MP3 | Voice_Generator | text를 TTS로 변환한 음성 |

## 출력

| 출력 | 형식 | 스펙 |
|------|------|------|
| 릴스 영상 | MP4 | 9:16 세로, 60초 이내, H.264 |
