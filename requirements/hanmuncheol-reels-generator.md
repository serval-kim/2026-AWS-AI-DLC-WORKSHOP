# 한문철 릴스 영상 생성기 - 요구사항 정의서

## 1. 프로젝트 개요

### 1.1 서비스 비전
블랙박스 영상 분석 결과(프롬프트)를 입력받아, 한문철 변호사가 사고를 해설하는 릴스 영상을 자동 생성하는 시스템.

### 1.2 핵심 가치 제안
- 블랙박스 분석 결과를 엔터테인먼트 콘텐츠로 자동 변환
- 한문철 스타일의 해설 영상을 AI로 생성
- 사고 영상과 합성 가능한 해설 클립 제공

---

## 2. 입력 스키마

```json
{
  "scenes": [
    {
      "blackbox_start_ts": "00:00:03",
      "blackbox_end_ts": "00:00:09",
      "blackbox_events": [
        {
          "start": "00:00:04",
          "end": "00:00:06",
          "event_type": "signal_violation"
        }
      ],
      "scene_description": "빨간 신호에 직진하는 SUV가 좌회전 차량과 충돌",
      "tts_script": "자 여기 보세요. 이 SUV가 빨간불인데 그냥 직진합니다. 이건 100% 신호위반이에요."
    }
  ]
}
```

---

## 3. 핵심 기능 요구사항

### 3.1 영상 생성 파이프라인

#### 입력
- 씬 배열 (위 스키마)
- 한문철 기본 이미지 (첫 프레임용)

#### 처리
1. 각 씬의 `tts_script`와 `scene_description`을 기반으로 Nova Reel 프롬프트 생성
2. 씬이 6초 초과 시 → 6초 단위로 분할하여 멀티샷 생성
3. 첫 씬의 첫 샷: 한문철 이미지를 시작 프레임으로 사용
4. 이후 샷: 이전 영상의 마지막 프레임을 시작 프레임으로 사용 (연속성 유지)
5. 생성된 샷들을 순서대로 결합

#### 출력
- 한문철 해설 영상 (MP4)
- 씬별 타임스탬프 매핑 (블랙박스 영상과 합성용)

### 3.2 프레임 연속성
- 이전 영상의 마지막 프레임 추출 (ffmpeg)
- 1280x720 리사이즈 후 다음 샷의 시작 이미지로 사용
- 스타일 일관성 유지

### 3.3 씬 분할 로직
- 씬 길이 = ceil(tts_script 길이 / 초당 글자수) 또는 (blackbox_end - blackbox_start)
- 6초 초과 시 → N개 샷으로 분할 (각 6초)
- 각 샷별 프롬프트는 해당 구간의 감정/액션에 맞게 변형

---

## 4. 기술 스택

| 컴포넌트 | 기술 |
|----------|------|
| 영상 생성 | Nova Reel v1:1 (MULTI_SHOT_MANUAL) |
| 프레임 추출 | ffmpeg (Lambda 또는 로컬) |
| 영상 결합 | ffmpeg |
| TTS | Amazon Polly 또는 외부 API |
| 오케스트레이션 | Python (Step Functions 또는 로컬) |
| 스토리지 | S3 |

---

## 5. 제약사항

- Nova Reel 프롬프트 최대 512자
- 이미지 입력 필수 1280x720
- 단일 샷 6초 고정
- 립싱크 불가 (영상은 해설자 비주얼만, 음성은 별도 TTS로 합성)
- 영상 생성 약 90초/샷 소요

---

## 6. MVP 범위

1. 단일 씬 입력 → 한문철 해설 영상 생성
2. 멀티샷 분할 (6초 단위)
3. 프레임 연속성 (마지막 프레임 → 다음 시작)
4. 최종 영상 결합 (ffmpeg)
